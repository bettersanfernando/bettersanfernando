# BetterSanFernando Documentation

These documents cover product and information architecture, civic-data
publication, frontend design, data readiness, and historical technical
decisions for the public BetterSanFernando repository.

## Historical documentation

[NEXTJS-MIGRATION-SPEC.md](NEXTJS-MIGRATION-SPEC.md) documents the completed
Next.js migration. It is retained for architectural and regression context;
it is not the current contributor or setup guide.

## Documentation principles

- Current documentation describes current behavior.
- Historical documentation is labeled as historical.
- Publication and data claims remain evidence-based.
- Contributor documentation must not require private-repository access.
