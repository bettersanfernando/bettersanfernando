# Provenance

This document records what has been factually verified about
BetterSanFernando's origins and third-party material. It is not legal
advice.

## Starter origin

Repository history and documentation identify
[`iyanski/betterlocalgov`](https://github.com/iyanski/betterlocalgov) as the
starter origin/reference for this project.

`betterlocalgov`'s license history shows CC0 1.0 was present before
BetterSanFernando was created from it. This document does not reproduce that
license text; see the [`betterlocalgov`](https://github.com/iyanski/betterlocalgov)
repository directly for its own license history.

## Third-party packages

npm dependencies used by this project remain subject to their own licenses
and terms, independent of this repository's own CC0 1.0 license.

`@bettergov/kapwa` specifically:

- Is used as an npm dependency of this project.
- Published package metadata inspected during this provenance review did not
  provide authoritative license/repository information.
- BetterSanFernando therefore makes no independent licensing claim about
  Kapwa. Contributors and downstream users should verify Kapwa's terms
  directly with its publisher before relying on any particular license.

## Civic/public-source material

BetterSanFernando publishes reviewed information derived from official and
public sources, with source provenance maintained alongside each published
record (see [`docs/SITE-ARCHITECTURE.md`](docs/SITE-ARCHITECTURE.md) and
[`docs/PAGE-DATA-MATRIX.md`](docs/PAGE-DATA-MATRIX.md)). This project does
not claim ownership of government documents, third-party source materials,
trademarks, or any other rights it does not control.

## Generated data

`src/data/generated/civic/` is a public-safe, reviewed export of civic data
(see the **Repository Boundary** section of [`CLAUDE.md`](CLAUDE.md)). Its
status as generated/published data does not by itself establish ownership of
the underlying source material it describes.
